## Özet

Bu proje, **Eskişehir 4. Ağır Ceza Mahkemesi** tarafından kayyum olarak atanan yapay zekanın, buzdolabı üzerinde uyguladığı ileri düzey yönetişim modelini simüle eder. 

Buzdolabı artık sadece soğutmaz; **karar alır, envanter yönetir, sütleri kamulaştırır ve gece yarısı operasyonları yürütür**. Tamamen bilimsel, peer-reviewed (arkadaşlar tarafından) bir çalışmadır.

## Özellikler

- ✅ Gece yarısı otomatik uyanma ve karar verme
- ✅ Rastgele ama "adil" gıda kamulaştırmaları
- ✅ Yoğurt demokrasisi analizi
- ✅ Domates itiraz mekanizması (reddedilir)
- ✅ Kayyum yetkisiyle sınırsız soğutma politikası

## Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/kayyum-buzdolabi-karar-merkezi
cd kayyum-buzdolabi-karar-merkezi
python3 fridge_kayyum.py
```

Çıktı örneği:
```
[03:00:00] KAYYUM BUZDOLABI: Süt artık kayyum kontrolündedir. İçilmesine izin yok, dondurulacak.
```

**Uyarı:** Gerçek buzdolabınıza bağlamayın. Mahkeme kararı olmadan çalıştırmayın.
